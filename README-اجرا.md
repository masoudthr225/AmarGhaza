# 🍽️ برنامه آمار غذا

## ▶️ اجرای برنامه (بدون پنجره CMD)

روی فایل **«اجرای برنامه.vbs»** دابل‌کلیک کنید.

برنامه در یک پنجره مستقل باز می‌شود — بدون پنجره مشکی CMD و بدون نوار آدرس مرورگر.

> اگر ویندوز پیام امنیتی داد، روی **More info** و سپس **Run anyway** بزنید.
> این پیام چون فایل امضای دیجیتال تجاری ندارد نمایش داده می‌شود.

### میان‌بر روی دسکتاپ
روی «اجرای برنامه.vbs» راست‌کلیک → **Send to** → **Desktop (create shortcut)**

---

## 📁 محتوای پوشه

| فایل / پوشه | توضیح |
|---|---|
| `اجرای برنامه.vbs` | ⭐ اجرای برنامه بدون CMD |
| `Run-AmarGhaza.bat` | روش جایگزین (پنجره CMD کوتاهی نشان می‌دهد) |
| `index.html` | صفحه اصلی برنامه |
| `css/` `js/` `assets/` | فایل‌های برنامه — حذف نکنید |
| `desktop/` | فایل‌های ساخت نسخه exe |
| `tools/` | ابزارهای جانبی |

---

## 💾 محل ذخیره اطلاعات

اطلاعات (پرسنل، واحدها، منو، آمار روز و تنظیمات چاپ) در پوشه `AppData`
کنار همین برنامه ذخیره می‌شود. یعنی **کاملاً پرتابل** است و می‌توانید
کل پوشه را روی فلش کپی کنید.

⚠️ برای پشتیبان‌گیری، از دکمه **ساخت زیپ** داخل خود برنامه استفاده کنید.
