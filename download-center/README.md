# 📦 مرکز دانلود — AmarGhaza Download Center

سروری سبک برای **آپلود فایل فشرده**، **ساخت ZIP از آخرین تغییرات** و **دانلود نتیجه** — فقط با پایتون استاندارد، بدون هیچ وابستگی.

## اجرا

```bash
cd download-center
python3 server.py            # پیش‌فرض: پورت 8000
# یا
DC_PORT=9000 python3 server.py
```

## سه دکمه / API

| دکمه | کار | متد و مسیر |
|---|---|---|
| ۱ | آپلود فایل فشرده و استخراج آن | `POST /api/upload?filename=نام‌فایل` (بدنهٔ درخواست = خود فایل) |
| ۲ | ساخت فایل ZIP از آخرین وضعیت/تغییرات فایل‌ها | `POST /api/archive?only_changed=0\|1` |
| ۳ | دانلود آخرین آرشیو ساخته‌شده | `GET /api/latest` |
| — | وضعیت فعلی (برای UI) | `GET /api/status` |

- `only_changed=1` → فقط فایل‌های تغییرکرده/افزوده‌شده داخل ZIP قرار می‌گیرند.
- داخل هر آرشیو فایل `CHANGES.txt` وجود دارد: گزارش کاملِ فایل‌های تغییرکرده/افزوده/حذف‌شده نسبت به نسخهٔ آپلودی شما.

## فرمت‌ها

- **پشتیبانی داخلی:** `zip` ، `tar` ، `tar.gz` ، `tgz` ، `tar.bz2` ، `tar.xz` ، `gz` ، `bz2` ، `xz`
- **در صورت نصب بودن ابزار:** `rar` و `7z` (با `7z` یا `unrar`)
- فایل‌های غیرآرشیوی (مثلاً docx یا pdf) به‌جای خطا، به‌صورت تک‌فایل ذخیره می‌شوند.

## ساختار داده‌ها (خارج از گیت)

```
download-center/data/
├── files/        ← فایل‌های استخراج‌شدهٔ کاربر (اینجا توسط ایجنت ویرایش می‌شود)
├── archives/     ← آرشیوهای ساخته‌شده (۱۰ مورد آخر نگه داشته می‌شود)
├── uploads/      ← فایل‌های آپلودی خام (۵ مورد آخر)
├── baseline.json ← نقشهٔ فایل‌ها در لحظهٔ آپلود (مبنای تشخیص تغییرات)
└── latest.json   ← مشخصات آخرین آرشیو
```

## متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `DC_PORT` / `PORT` | `8000` | پورت سرور |
| `DC_HOST` | `0.0.0.0` | آدرس اتصال |
| `DC_MAX_UPLOAD` | `1073741824` | سقف حجم آپلود (بایت) |
| `DC_DATA_DIR` | `./data` | پوشهٔ داده‌ها |

## امنیت

- محافظت **Zip-Slip** (جلوگیری از استخراج به خارج از پوشهٔ مقصد)
- نام فایل‌ها پاک‌سازی می‌شوند (بدون مسیر و کاراکترهای خطرناک)
- سقف حجم آپلود قابل تنظیم
