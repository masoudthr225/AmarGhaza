# 🥇 سیستم ثبت ری‌گیری طلا — نسخهٔ پایتون

برنامهٔ کامل مدیریت ری‌گیری طلا، بازنویسی‌شده با **پایتون** — بدون هیچ وابستگی، بدون نصب، بدون نیاز به اینترنت.

> ⚡ **تفاوت با نسخهٔ قبل:** دیگر Node.js لازم نیست، هیچ `npm install` و Build و دانلودی در کار نیست — برنامه در همان لحظهٔ اول اجرا می‌شود. اگر قبلاً نسخهٔ Node را داشتید، نگران نباشید: **داده‌های شما (فایل `db\custom.db`) دقیقاً همان است و همین برنامه آن را می‌خواند.**

---

## 🚀 اجرا (فقط ۳ قدم)

1. فایل زیپ را **کامل Extract کنید** (راست‌کلیک → Extract All) — از داخل پنجرهٔ زیپ اجرا نکنید.
2. مطمئن شوید **Python 3** روی ویندوز نصب است (یک‌بار برای همیشه؛ از [python.org](https://www.python.org/downloads/) با تیک **Add python.exe to PATH**).
3. روی **«اجرای برنامه.vbs»** دابل‌کلیک کنید — مرورگر خودکار باز می‌شود: `http://127.0.0.1:3000`

💡 راحت‌تر: یک‌بار **«میان‌بر دسکتاپ.vbs»** را اجرا کنید تا آیکون برنامه روی دسکتاپ ساخته شود.

---

## 🔄 ارتقا از نسخهٔ قبلی (Node.js)

اگر نسخهٔ قدیمی را روی کامپیوترتان داشته‌اید و بعد از آن **رکورد جدیدی ثبت کرده‌اید**، قبل از جایگزینی:

1. از پوشهٔ برنامهٔ قدیمی، پوشهٔ `db` را کپی کنید (یا از داخل برنامهٔ قدیمی «دانلود فایل بکاپ» بزنید).
2. زیپ نسخهٔ جدید را در یک پوشهٔ تازه Extract کنید.
3. پوشهٔ `db` قدیمی را **جایگزین** پوشهٔ `db` نسخهٔ جدید کنید (یا فایل بکاپ `.db` را از داخل برنامهٔ جدید → «بکاپ و بازیابی» → «آپلود و بازیابی» وارد کنید).

اگر بعد از آخرین بروزرسانی چیزی ثبت نکرده‌اید، نیازی به هیچ کاری نیست — داده‌ها داخل همین بسته به‌روز است.

## 📁 فایل‌ها

| فایل | کاربرد |
|---|---|
| `اجرای برنامه.vbs` | ⭐ اجرای اصلی (بی‌صدا + باز شدن خودکار مرورگر + نگهبان) |
| `app.py` | کل برنامه — یک فایل پایتون با کتابخانهٔ استاندارد |
| `ui.html` | رابط کاربری فارسی برنامه |
| `db\custom.db` | 💾 دیتابیس — **همان فایل قبلی؛ همهٔ داده‌ها همین‌جاست** |
| `db\backups\` | بکاپ‌های خودکار/دستی/قبل از بازیابی |
| `خروجی\` | 📁 مقصد فایل‌های اکسل و بکاپ دستی (مسیر قابل تنظیم) |
| `assets\` | تصویر پس‌زمینه و فونت فارسی |
| `میان‌بر دسکتاپ.vbs` | ساخت میان‌بر روی دسکتاپ |
| `STOP.bat` | توقف کامل برنامه |
| `START.bat` | اجرای کنسولی (برای عیب‌یابی — لاگ‌ها را نشان می‌دهد) |
| `CHECK.bat` | چک سلامت سیستم (پایتون؟ فایل‌ها؟ دیتابیس؟) |
| `logs\launcher.log` | گزارش اجرا (اگر مشکلی بود این را ببینید) |

## ✨ امکانات

- ثبت / ویرایش / جستجو / فیلتر (نوع کار، وضعیت عیار) / مرتب‌سازی / صفحه‌بندی
- **تقویم شمسی بازشو** برای انتخاب تاریخ ثبت (به‌همراه دکمهٔ «امروز»)؛ تایپ دستی تاریخ هم همچنان ممکن است
- **عیار خالی**: اگر عیار دریافتی خالی ثبت شود، در ستون «وضعیت عیار» «در انتظار عیار» نمایش داده می‌شود
- **حذف ایمن**: رکورد حذف‌شده از فهرست برداشته می‌شود ولی نسخهٔ امن آن در بکاپ‌ها باقی می‌ماند
- **خروجی Excel** (xlsx) و **آپلود Excel/CSV** — رکورد تکراری رد می‌شود، هیچ داده‌ای پاک نمی‌شود
- **بکاپ و بازیابی**: بکاپ خودکار در هر اجرا (۲۰ نسخهٔ آخر) + بکاپ دستی + دانلود فایل بکاپ + بازیابی از فایل
- **مسیر خروجی فایل‌ها**: خروجی اکسل و بکاپ‌های دستی در پوشهٔ خروجی ذخیره می‌شوند — پیش‌فرض پوشهٔ «خروجی» کنار برنامه؛ مسیر دلخواه (مثلاً `D:\GoldOutput`) را می‌توانید بالای پنجرهٔ «بکاپ و بازیابی» تعیین کنید
- **صفر کردن برنامه**: دکمهٔ حذف همهٔ اطلاعات (در پنجرهٔ بکاپ و بازیابی) — با رمز محافظت می‌شود و قبل از پاک‌سازی، خودکار نسخهٔ امن گرفته می‌شود
- **نگهبان (Watchdog)**: اگر سرور به هر دلیلی بسته شود، خودش دوباره بالا می‌آورد
- **آلارم صوتی**: با زدن «ذخیره» آلارم ثبت پخش می‌شود و بعد از تایید موفق سرور، آلارم تایید (کاملاً آفلاین، بدون فایل صوتی)
- **اسکرول مستقل لیست رکوردها**: جدول با سرستونِ ثابت بالا و پایین اسکرول می‌شود
- اجرای کاملاً بی‌صدا (بدون پنجرهٔ سیاه CMD)
- تاریخ‌ها شمسی، اعداد فارسی، فونت وزیرمتن آفلاین

## ❓ رفع اشکال

| مشکل | راه‌حل |
|---|---|
| پیام «پایتون نصب نیست» | از python.org نسخهٔ Python 3 را نصب کنید و حتماً تیک **Add python.exe to PATH** را بزنید |
| پیام «فایل‌ها استخراج نشده‌اند» | زیپ را Extract کنید و از داخل پوشهٔ استخراج‌شده اجرا کنید |
| مرورگر باز نمی‌شود ولی برنامه در حال اجراست | خودتان آدرس `http://127.0.0.1:3000` را باز کنید |
| برنامه بالا نمی‌آید | `START.bat` را اجرا کنید تا خطا در پنجره نمایش داده شود؛ سپس `logs\launcher.log` را ببینید |
| می‌خواهم مطمئن شوم همه‌چیز سالم است | `CHECK.bat` را اجرا کنید |
| برنامه بسته نمی‌شود | `STOP.bat` را اجرا کنید |

---

## 🔒 نکتهٔ امنیتی داده‌ها

- همهٔ داده‌ها فقط روی همین کامپیوتر (در `db\custom.db`) ذخیره می‌شود و هیچ‌جا ارسال نمی‌شود.
- برای امنیت بیشتر، هر از گاهی از داخل برنامه «دانلود فایل بکاپ» را بزنید و فایل `.db` را روی فلش یا جای امن نگه دارید.
