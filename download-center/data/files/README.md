# 🥇 سیستم ثبت ری‌گیری طلا

برنامهٔ ثبت، جستجو و گزارش ری‌گیری نمونه‌های طلا — سازگار با ویندوز ۱۰ و ۱۱

---

## ⚡ شروع سریع (فقط ۲ قدم)

1. روی **«اجرای برنامه.vbs»** دابل‌کلیک کنید — هیچ پنجرهٔ سیاهی باز نمی‌شود
2. صبر کنید تا مرورگر به‌صورت خودکار باز شود (`http://127.0.0.1:3000`)

> 💡 اولین اجرا چند دقیقه طول می‌کشد (نصب خودکار وابستگی‌ها + ساخت برنامه). دفعات بعد سریع است.
>
> 💡 برای دسترسی راحت‌تر، یک‌بار **«میان‌بر دسکتاپ.vbs»** را اجرا کنید تا میان‌بر «سیستم ری‌گیری طلا» روی دسکتاپ ساخته شود.

**توقف برنامه:** روی `STOP.bat` دابل‌کلیک کنید.

---

## 📁 فایل‌های مهم

| فایل | کاربرد |
|------|--------|
| **اجرای برنامه.vbs** | اجرای اصلی برنامه — بی‌صدا و بدون پنجرهٔ سیاه ✅ |
| **میان‌بر دسکتاپ.vbs** | ساخت میان‌بر «سیستم ری‌گیری طلا» روی دسکتاپ (یک‌بار) |
| **STOP.bat** | توقف کامل و تمیز برنامه |
| **START.bat** | اجرای همراه با کنسول (برای عیب‌یابی) |
| **CHECK.bat** | بررسی سلامت سیستم (نود، دیتابیس، پورت و…) |
| `scripts/launcher.mjs` | نگهبان برنامه: نصب، ساخت، اجرای مخفی، بازکردن مرورگر، راه‌اندازی مجدد خودکار |
| `db/custom.db` | دیتابیس اصلی برنامه (رکوردهای شما) |
| `db/backups/` | پشتیبان‌های خودکار دیتابیس (۲۰ نسخهٔ آخر) |
| `logs/launcher.log` | لاگ کامل اجرای برنامه |

## ✨ امکانات

- ثبت رکورد ری‌گیری با شماره پاکت، وزن، عیار و نوع کار (النگو / ریخته‌ای)
- **وضعیت عیار خودکار** با برچسب استاندارد: «استاندارد (750)» / «بالا (>750)» / «پایین (<750)»
- جستجو، فیلتر (نوع کار، وضعیت عیار) و مرتب‌سازی روی همهٔ ستون‌ها
- **آپلود فایل اکسل** (`.xlsx` / `.xls` / `.csv`) — بدون پاک شدن داده‌های قبلی؛ رکوردهای تکراری رد می‌شوند
- **خروجی Excel** با تمام ستون‌ها
- **بکاپ و بازیابی** — دکمهٔ «بکاپ و بازیابی» در بالای برنامه:
  - 💾 گرفتن نسخهٔ پشتیبان داخل برنامه (ذخیره در `db/backups`)
  - 📥 دانلود فایل بکاپ (`.db`) روی کامپیوتر یا فلش
  - ♻️ بازیابی با یک کلیک از فهرست بکاپ‌ها **یا** آپلود فایل بکاپ
  - قبل از هر بازیابی، از وضعیت فعلی به‌طور خودکار نسخهٔ امن گرفته می‌شود
- **سطل بازیافت (حذف نرم):** حذف رکورد آن را برای همیشه نمی‌ریزد — با یک کلیک برمی‌گردد
- **نگهبان خودکار:** اگر برنامه بسته شود خودش دوباره بالا می‌آید؛ اگر ۳ بار در ۶۰ ثانیه کرش کند پیام خطا می‌دهد
- ذخیرهٔ خودکار فرم در حال تکمیل (اگر صفحه بسته شد، از دست نمی‌رود)
- کلید میانبر ثبت جدید: `Insert` — جابه‌جایی بین فیلدها با `Enter`

## 🛡 چهار لایهٔ محافظت داده

| لایه | توضیح |
|------|--------|
| ۱️⃣ سطل بازیافت | حذف رکورد فقط آن را به سطل بازیافت می‌برد؛ از دکمهٔ «سطل بازیافت» بالای صفحه با یک کلیک برمی‌گردد |
| ۲️⃣ بکاپ خودکار | قبل از هر اجرا، از دیتابیس در `db/backups/` نسخهٔ پشتیبان گرفته می‌شود (۲۰ نسخهٔ آخر نگه داشته می‌شود) |
| ۳️⃣ بکاپ دستی و بازیابی | از داخل برنامه هر وقت بخواهید بکاپ بگیرید (یا فایلش را دانلود کنید) و با یک کلیک بازیابی کنید |
| ۴️⃣ آپلود بدون بازنویسی | آپلود فایل اکسل هیچ رکورد قبلی را پاک نمی‌کند؛ فقط رکوردهای جدید اضافه و تکراری‌ها رد می‌شوند |

## 🔄 اجرای برنامه چطور کار می‌کند؟

```
اجرای برنامه.vbs (بررسی نصب Node.js → اجرای مخفی)
        │
        ▼
scripts/launcher.mjs (نگهبان)
        │
        ├─ ۱. جلوگیری از اجرای همزمان دو نسخه (فقط مرورگر باز می‌شود)
        ├─ ۲. نصب وابستگی‌ها (فقط اولین اجرا)
        ├─ ۳. پشتیبان‌گیری از دیتابیس (db/backups)
        ├─ ۴. ساخت برنامه در صورت تغییر فایل‌ها
        ├─ ۵. اجرای مخفی سرور روی 127.0.0.1:3000
        ├─ ۶. باز کردن خودکار مرورگر
        └─ ۷. زیر نظر نگه‌داشتن سرور و راه‌اندازی مجدد خودکار
```

## 🔧 رفع اشکال

| مشکل | راه‌حل |
|------|--------|
| پیام «فایل‌های برنامه کامل استخراج نشده‌اند» | فایل زیپ را از داخل پنجرهٔ زیپ اجرا نکنید! راست‌کلیک روی زیپ → **Extract All** و بعد «اجرای برنامه.vbs» را اجرا کنید |
| پیام «Node.js نصب نیست» یا نسخهٔ قدیمی | از `nodejs.org` نسخهٔ LTS (حداقل نسخهٔ ۲۰) را نصب و کامپیوتر را ری‌استارت کنید |
| اولین اجرا طول کشید | طبیعی است (نصب + ساخت با پنجرهٔ پیشرفت). لاگ پیشرفت: `logs/launcher.log` |
| نصب اولیه نیمه‌کاره ماند | اینترنت را بررسی کنید و دوباره «اجرای برنامه.vbs» را اجرا کنید (از همان‌جا ادامه می‌دهد) |
| مرورگر باز نشد | خودتان `http://127.0.0.1:3000` را باز کنید |
| برنامه بعد از بستن دوباره بالا آمد | نگهبان فعال است؛ برای توقف کامل `STOP.bat` را اجرا کنید |
| صفحه «در حال بارگذاری» ماند | `CHECK.bat` را اجرا کنید و وضعیت را ببینید |
| رکورد اشتباهی حذف شد | دکمهٔ «سطل بازیافت» → دکمهٔ چرخش ⟲ کنار رکورد |
| برگرداندن کل داده‌ها به قبل | دکمهٔ «بکاپ و بازیابی» → انتخاب نسخه → «بازیابی» (یا آپلود فایل `.db`) |
| بازیابی از فایل بکاپ روی فلش | دکمهٔ «بکاپ و بازیابی» → «آپلود و بازیابی از فایل بکاپ (.db)» |
| فایل بکاپ معتبر شناخته نشد | فایل باید دیتابیس SQLite همین برنامه باشد (پسوند `.db` و تهیه‌شده از دکمهٔ بکاپ) |
| برنامه بالا نیامد | `START.bat` را اجرا کنید تا خطا در پنجرهٔ کنسول نمایش داده شود؛ جزئیات در `logs/launcher.log` |
| داده‌ها گم شدند | از `db/backups/` آخرین نسخه را بردارید و جای `db/custom.db` بگذارید (اول برنامه را با `STOP.bat` ببندید) |
| پورت ۳۰۰۰ اشغال است | برنامهٔ دیگر را ببندید یا در `START.bat` پورت را عوض کنید |
