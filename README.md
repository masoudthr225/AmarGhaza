# doreKarii — برنامه آمار غذا 🍽️

برنامه ثبت و چاپ آمار ناهار، عصرانه و شام پرسنل — با پشتیبانی از همه پرینترها از جمله پرینتر حرارتی رولی.

## اجرا
- روی سرور: پوشه را با هر وب‌سرور ساده سرو کنید (مثلاً `python3 -m http.server 8000`) و `index.html` را باز کنید.
- آفلاین: دابل‌کلیک روی `index.html` هم کار می‌کند (بررسی خودکار به‌روزرسانی فقط در حالت سرور فعال است).

## ساختار فایل‌ها (ماژولار — برای به‌روزرسانی جزئی)
```
index.html          پوسته برنامه و لودر نسخه‌دار
css/app.css         استایل‌ها
js/manifest.js      نسخه برنامه + اثرانگشت (هش) هر فایل  ← خودکار ساخته می‌شود
js/store.js         داده‌ها و ذخیره‌سازی خودکار (localStorage)
js/jalali.js        تقویم شمسی (جلالی)
js/sheet.js         تب آمار روز و حضور/غیاب
js/manage.js        پرسنل، واحدها، وعده‌ها و منو
js/pagesetup.js     تنظیمات صفحه (Page Setup)
js/print.js         ساخت سند، پیش‌نمایش، چاپ و پشتیبان‌گیری
js/excel.js         آپلود و دانلود اکسل
js/updater.js       سیستم به‌روزرسانی
js/main.js          شروع برنامه
js/xlsx.full.min.js کتابخانه اکسل (SheetJS — آفلاین)
tools/build-manifest.py   اسکریپت ساخت manifest بعد از هر تغییر
```

## 🔄 روند به‌روزرسانی (فقط فایل‌های تغییرکرده جایگزین می‌شوند)

هر فایل با اثرانگشت خودش بارگیری می‌شود (`app.css?v=f605f2b7b6`). وقتی فایلی
تغییر کند هشش عوض می‌شود و مرورگر **فقط همان فایل** را دوباره دانلود می‌کند؛
بقیه فایل‌ها از کش مرورگر خوانده می‌شوند.

### برای انتشار نسخه جدید:
1. فایل(های) موردنظر را ویرایش کنید (مثلاً فقط `js/print.js`).
2. اجرا کنید:
   ```bash
   python3 tools/build-manifest.py --bump
   ```
   (بدون `--bump` فقط هش‌ها به‌روز می‌شوند و شماره نسخه ثابت می‌ماند)
3. فایل‌های تغییرکرده + `js/manifest.js` را روی سرور کپی کنید — همین!

### سمت کاربر:
- هنگام باز شدن برنامه، به‌صورت بی‌صدا بررسی می‌شود و اگر نسخه جدیدی باشد پیشنهاد به‌روزرسانی می‌آید.
- یا از دکمه «🔄 بررسی به‌روزرسانی» در نوار بالای برنامه.
- فقط فایل‌های تغییرکرده دانلود می‌شوند و **اطلاعات کاربر (پرسنل، منو، تنظیمات، آمار) دست‌نخورده می‌ماند** چون در localStorage مرورگر ذخیره است، جدا از فایل‌های برنامه.

## قابلیت‌ها
- چاپ لیست ناهار/عصرانه/شام با نام و کد پرسنلی
- پشتیبانی A4/A5/Letter + پرینتر حرارتی رول ۸۰ و ۵۸ میلی‌متر + اندازه دلخواه
- Page Setup کامل: حاشیه، فونت، سایز، هدر و فوتر، ستون‌بندی و…
- غایب‌زدن با کلیک → خط‌خوردن نام در برنامه و روی کاغذ چاپی
- انتخاب تک/چند واحد، مدیریت کامل پرسنل/واحد/وعده/منو
- تقویم شمسی بازشونده، آپلود/دانلود اکسل، پشتیبان‌گیری JSON
